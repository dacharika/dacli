# Operating boundaries

The host owns inspect/plan/implement/review cycles. Choose one bounded task or a set of non-overlapping tasks using canonical readiness; configure concurrency and spending in the host. There is no dacli start profile or service supervisor. Inspect task scope and the current native session before attempting any lease.

See the [operator playbook](https://github.com/mlnomadpy/dacli/blob/main/docs/OPERATOR_PLAYBOOK.md) and inspect `dacli capabilities --json` for the installed surface.

# Recovery without invented authority

Use bounded historical runs/logs/replay and current native identity observations. A prior successful receipt is not a live lease; expired or revoked sessions must refuse. Preview cleanup and apply only its exact safe plan. Unknown liveness, divergent files and referenced evidence stay protected. Restore never overwrites existing material. Project deletion has no preview mode and irreversibly removes project records; it is not a recovery command. Never delete or hand-edit private authority to bypass a refusal.

See the [operator playbook](https://github.com/mlnomadpy/dacli/blob/main/docs/OPERATOR_PLAYBOOK.md) and inspect `dacli capabilities --json` for the installed surface.

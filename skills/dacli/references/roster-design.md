# Roles and authority

Role files describe scope, skills, escalation and intended responsibilities. They help the host plan work but do not authenticate native principals. Runtime/model fields in historical roles do not select a provider process. Independent reviewers need eligible credential families, owner grants and exact revision evidence, not merely another role name.

See the [operator playbook](https://github.com/mlnomadpy/dacli/blob/main/docs/OPERATOR_PLAYBOOK.md) and inspect `dacli capabilities --json` for the installed surface.

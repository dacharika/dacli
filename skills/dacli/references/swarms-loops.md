# Native delegation

Create and supervise agents using the native host. Register external checkouts and scoped leases through governance tools. A shared MCP connection has one session identity even when native children call it. Independent review requires separately eligible credential families and explicit grants. Never wrap a coding CLI to simulate native delegation.

See the [operator playbook](https://github.com/mlnomadpy/dacli/blob/main/docs/OPERATOR_PLAYBOOK.md) and inspect `dacli capabilities --json` for the installed surface.

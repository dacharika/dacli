# Native delegation

The native host creates, delegates, routes, and reviews coding agents. Register
an externally created clean checkout as an attempt, then acquire and renew its
scoped lease through the selected governance tools. A shared MCP connection
has one session identity even when native children call it. Independent review
requires separately eligible credential families and explicit grants. Never
wrap a coding CLI to simulate native delegation.

The controller records exact task binding, attempt identity, lease scope,
revision publication, and self-reported check results. It does not dispatch a
prompt to a host, open a new chat, or run child code. The human or host owner
must perform each host action and report the observed result. A successful
source build or fixture test does not qualify that behavior in a live host.

Do not infer concurrency from configured width, leases, or a host declaration.
Availability and independently qualified concurrency are separate facts; if
the selected runtime does not expose a fresh observation, leave capacity
unknown. Do not start admission or scheduling from a missing, stale, or
unqualified fact.

Cancellation is also a host boundary. A governance cancellation request does
not kill a process. The host owner stops or observes the exact process and
records the acknowledgement manually. No automatic delivery or termination
is implied.

See the [operator playbook](https://github.com/mlnomadpy/dacli/blob/main/docs/OPERATOR_PLAYBOOK.md) and inspect `dacli capabilities --json` for the installed surface.

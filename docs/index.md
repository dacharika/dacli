# dacli

![license: BSD--3--Clause](https://img.shields.io/badge/license-BSD--3--Clause-blue)

Governance for agents running in their native coding host. Codex is the first
measured plugin integration: scoped sessions, external Git attempts, fenced
leases and committed revision evidence. The host runs agents; dacli governs
operations through its explicit interfaces.

Build the native preview from the reviewed source checkout and follow the
[Codex plugin setup](https://github.com/mlnomadpy/dacli/blob/main/plugins/codex/README.md).
The published v0.3.1 archives contain the older launcher product, not this native
preview. Provider launchers and runtime adapters are removed from current source.

Start with the [operator playbook](OPERATOR_PLAYBOOK.md),
[native transport](GOVERNANCE_NATIVE_MCP.md), [documentation index](README.md)
and [pitch deck](pitch/index.html).

This is a cooperative local preview. A shared MCP connection shares one session;
self-reports are not trusted runner evidence, and native final acceptance remains
future work. Credentials and owner decisions use private durable storage, while
canonical project documents remain readable Markdown.
